# Feature specs

Specs produced by the **agentic-feature** workflow live here.

| Status | Meaning |
| --- | --- |
| `draft` | Spec + BDD written; awaiting human approval |
| `approved` | Human gate passed; implementation in progress or done |
| `implemented` | BDD green and behavior shipped |

Naming: `docs/specs/<feature-slug>.md` (kebab-case).

Workflow: `.agents/skills/agentic-feature/SKILL.md`.
